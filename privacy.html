Broken Pizza Gestion — dernière mise à jour : septembre 2026

Cette application mobile (« Broken Pizza Gestion ») est destinée aux opérateurs de food-trucks de la franchise Broken Pizza. Elle permet la gestion opérationnelle (produits, inventaires, recettes, hygiène, finance) hors ligne, avec synchronisation cloud optionnelle.

1. Responsable

Broken Pizza / éditeur de l’application. Contact : pizzabroken38@gmail.com

2. Données traitées

  • Identifiants de compte (e-mail, authentification via Supabase).
  • Données métier saisies dans l’app : stocks, inventaires, recettes, contrôles d’hygiène, écritures financières.
  • Photos d’étiquettes / preuves liées aux contrôles (stockées localement et, si sync activée, dans le stockage cloud du compte).
  • Métadonnées de synchronisation (horodatages, manifeste de version des données).

L’application ne cible pas le grand public ; elle est utilisée dans un cadre professionnel franchise.

3. Finalités

  • Fournir les fonctions de gestion du camion.
  • Sauvegarder et synchroniser les données entre appareils via le compte utilisateur.
  • Permettre un suivi franchise ( consoles d’administration autorisées ).

4. Base légale / conservation

Traitement nécessaire à l’exécution du service demandé par l’utilisateur (compte professionnel). Les données sont conservées tant que le compte est actif et que les sauvegardes cloud / locales existent ; suppression sur demande ou fermeture de compte.

5. Hébergement et sous-traitants

Authentification et stockage cloud : Supabase (infrastructure cloud). Distribution de l’application : Google Play.

6. Partage

Les données d’un compte camion ne sont pas vendues. Elles peuvent être consultées par l’administration franchise autorisée dans le cadre du suivi opérationnel. Google peut traiter des données techniques liées à l’installation via Play Store selon sa propre politique.

7. Sécurité

Accès par compte authentifié. Données locales sur l’appareil ; sync chiffrée en transit (HTTPS). Une désinstallation sans export / sync peut entraîner une perte de données locales.

8. Droits

Pour accéder, rectifier ou supprimer les données de votre compte, contactez pizzabroken38@gmail.com.

9. Permissions Android

  • Stockage / photos : import et capture d’images d’étiquettes.
  • Microphone (si activé) : fonctions vocales éventuelles de saisie.

10. Modifications

Cette page peut être mise à jour ; l’URL publique reste celle utilisée dans la fiche Play Store.
